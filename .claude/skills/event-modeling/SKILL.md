# Моделирование событий спроса

Метод оценки бизнес-идей для конкретной локации. Идея метода: бизнес живёт не на «населении» и не на «трафике», а на **событиях спроса** — повторяющихся моментах, когда у конкретного человека возникает потребность и он готов заплатить. Мы перечисляем эти события, оцениваем их частоту и чек, и смотрим, какую долю событий новая точка реально перехватит.

Деньги бизнеса = Σ по сегментам ( численность × частота события × средний чек × доля перехвата ).

## Шаг 0. Сбор фактов (обязательно с поиском в интернете)

Не начинай моделирование без данных. Найди и зафиксируй с источниками:

1. **Население и динамика** — сколько людей, растёт или падает, за счёт чего (рождаемость / миграция).
2. **Структура населения** — возраст, размер семей, этнический/культурный состав (он определяет паттерны трат: праздники, еда, отношение к кредитам).
3. **Доходы** — средняя зарплата по региону И реальная зарплата на месте (они сильно различаются; смотри вакансии на hh/Авито по локации).
4. **Что уже есть** — карта конкурентов: 2ГИС/Яндекс.Карты, справочники, объявления. Отдельно отметь, что есть в ближайшем крупном населённом пункте и сколько до него ехать.
5. **Стоимость входа** — цена участка/аренды, примерный капекс по нише (ищи свежие разборы, но помни: цифры франшиз и продавцов оборудования завышены — дисконтируй их выручку на 30–50 %).

## Шаг 1. Сегменты

Разбей население на 3–6 сегментов, различающихся поведением, а не только возрастом. Пример: «многодетные семьи с одним работающим», «работающие в соседнем городе (маятниковая миграция)», «пенсионеры», «молодёжь 16–25». Для каждого сегмента — численность (оценка с вилкой) и располагаемый доход.

## Шаг 2. Каталог событий спроса

Для каждого сегмента перечисли события по частоте:

| Класс | Частота | Примеры |
|---|---|---|
| Ежедневные | 1×/день и чаще | хлеб, продукты, кофе по дороге на работу |
| Еженедельные | 1–3×/нед | посылки с маркетплейсов, рынок, мойка машины |
| Ежемесячные | ~1×/мес | стрижка, аптека, хозтовары, корм для животных |
| Сезонные | несколько раз/год | стройка/ремонт, школьный сезон, рассада |
| Редкие крупные | раз в годы | свадьба, юбилей, похороны/поминки, покупка техники |

Ключевые вопросы к каждому событию:
- **Где оно закрывается сейчас?» (местный конкурент / соседний город / онлайн / никак).** Событие, которое сейчас закрывается «в соседнем городе» или «никак», — главный кандидат.
- **Эластично ли оно к доходу?** Хлеб покупают при любой зарплате, кофе за 200 ₽ — нет. В бедной локации выигрывают неэластичные события.
- **Совместимо ли с культурой сегмента?** (алкоголь, праздники, гендерные паттерны трат).

## Шаг 3. Модель перехвата

Для каждой ниши-кандидата посчитай консервативно и оптимистично:

```
Выручка/мес = сегмент × частота(соб./мес) × чек × доля перехвата
Прибыль/мес ≈ Выручка × маржа ниши − фикс. расходы (аренда, ФОТ, коммуналка)
Окупаемость = (капекс + участок/помещение) / прибыль
```

Доля перехвата — самое честное место модели. Ориентиры: у единственной точки в шаговой доступности при ежедневном событии — 30–60 %; при наличии конкурента — 10–25 %; для дискреционных трат (кофе, десерты) в небогатой локации — считай от пессимистичного края.

## Шаг 4. Стресс-события

Прогони модель через сценарии: «зарплаты не растут 3 года», «сетевой конкурент открывает такой же формат», «отток молодёжи», «ключевой сегмент перестаёт расти». Ниша, которая выживает во всех сценариях, ценнее ниши с красивым базовым сценарием.

## Шаг 5. Вывод

- Ранжируй ниши по: прибыль/капекс, устойчивость к стрессам, соответствие событиям, которые сейчас «не закрыты».
- Ищи **комбо-эффекты**: две-три ниши на одной точке делят аренду и делятся трафиком (якорное ежедневное событие тянет дискреционные: пекарня → кофе, ПВЗ → сопутствующие товары).
- Заверши списком **полевых проверок**, которые пользователь должен сделать ногами до покупки участка: счёт прохожих/машин в час в будни и выходные, опрос 20–30 местных, цены и загрузка конкурентов в соседнем городе.

## Формат результата

Отчёт в markdown: факты с источниками → сегменты → каталог событий → таблица сравнения ниш (капекс, прибыль вилкой, окупаемость, риски) → рекомендация → полевые проверки. Все допущения помечай явно и давай вилки, а не точные числа.
