# Анализ бизнес-идей: моделирование событий

Репозиторий с навыком анализа для Claude Code и результатами его применения.

## Структура

- **`.claude/skills/event-modeling/SKILL.md`** — навык «моделирование событий спроса»: методика оценки бизнес-идей для конкретной локации. Подключается автоматически в Claude Code; вызывай фразами вида «проанализируй, что открыть в …».
- **`analysis/pshekhskaya-biznes-analiz.md`** — первый прогон навыка: что открыть на участке в центре станицы Пшехской (Белореченский район, Краснодарский край). Вывод: пекарня + кофе-угол + ПВЗ как фаза 1, банкетный зал как фаза 2.

## Как пользоваться навыком

В сессии Claude Code в этом репозитории попроси: «Смоделируй события спроса для <локация> и сравни ниши <А, Б, В>». Навык требует поиска актуальных данных в интернете, даёт вилки вместо точных цифр и всегда заканчивает списком полевых проверок.
